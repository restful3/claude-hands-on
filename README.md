# 답하는 AI에서, 일하는 AI로

코딩 경험이 없어도 Claude App·Code에 작업 폴더·권한·MCP·Skill·Plugin을 연결해  
새 업무에 다시 쓰는 **업무 하네스 한 세트**를 완성하는 4시간 오프라인 핸즈온입니다.

[커리큘럼 확인하고 리허설 참가 신청하기](https://restful3.github.io/claude-hands-on/)

## 리허설 안내

- 대상: Claude에게 조언만 받는 단계를 넘어 실제 업무 결과물을 맡기고 싶은 비개발자
- 일정: 2026년 8월 15일 이후 토요일 오후 1시~5시 중 가능일 복수 선택
- 확정: 공통 일정이 맞는 4~5인
- 장소: 서울 마곡·가양 인근 오프라인 스터디룸
- 참가비: 파일럿 리허설 5만원
- 준비물: 개인 노트북, Claude 유료 플랜

## 4시간에 연결하는 것

1. Claude App·Code 작업대와 권한·Plan·diff
2. MCP·Connector를 통한 외부 도구 연결
3. 반복 업무 절차를 저장하는 나만의 Skill
4. Skill·Agent·Hook·MCP 구조를 묶은 Plugin 하네스

메뉴를 둘러보는 데서 끝내지 않고, 업무 메일과 자료에서 근거표·제안서·수정본을 만든 뒤 새 업무에 다시 실행합니다.
