4시간, Claude 업무 하네스를 직접 조립합니다

처음 보는 단어가 있어도 괜찮습니다. MCP는 바깥 자료를 읽어 오는 연결, Skill은 반복 절차를 적어 두는 파일, Plugin은 그것들을 한 세트로 묶는 꾸러미입니다. 네 세션 모두 용어를 먼저 풀어 설명한 뒤 직접 손으로 만듭니다.

S1
0:00 – 0:50

Claude App·Code 작업대 설정

Desktop/Cowork와 Code의 역할을 나누고, 작업 폴더·CLAUDE.md(업무 기준을 적어 두는 메모 파일)·권한·Plan(실행 전 계획 확인)·diff(바뀐 부분 비교)를 설정합니다.

S2
1:00 – 1:50

MCP·Connector로 외부 도구 연결

MCP·Connector는 Claude가 바깥 자료를 읽어 오도록 잇는 통로입니다. 실습용 Gmail/Drive 중 하나를 읽기 전용으로 호출하고, 도구·권한·결과를 연결 기록에 남깁니다.

S3
2:00 – 2:50

반복 업무를 Skill로 저장

자주 하는 일의 순서를 파일 하나에 적어 두면 다음부터 그대로 불러 씁니다. 메일→근거표→제안서 절차를 SKILL.md로 만들고 직접 호출해 결과와 diff를 검수합니다.

S4
3:00 – 3:50

Plugin으로 업무 하네스 완성 전이 확인

Plugin은 지금까지 만든 것을 한 상자에 담는 포장입니다. 무엇이 들었는지 적은 목록(manifest), 절차(Skill), 대신 일하는 역할(Agent), 자동으로 끼어드는 규칙(Hook), 외부 연결(MCP) 구조를 읽고 로컬 Plugin을 불러와 새 업무에서 다시 실행합니다.

궁금한 점

개발을 전혀 몰라도 되나요?+
네. 프로그래밍 문법은 다루지 않습니다. 다만 폴더·설정 파일을 열고 짧은 명령을 실행하므로, 보내드리는 사전 설치·연결 점검은 꼭 완료해야 합니다.
MCP·Skill·Plugin, 미리 알아야 하나요?+
아닙니다. 쉬운 말로 MCP는 바깥 자료를 읽어 오는 연결, Skill은 반복 절차를 적어 둔 파일, Plugin은 그 둘을 한 세트로 묶은 꾸러미입니다. 그리고 이 셋을 합쳐 하나의 작업 환경으로 만든 것이 업무 하네스입니다. 각 세션은 용어를 먼저 풀어 설명한 뒤 실습으로 넘어가므로, 외워 오실 것은 없습니다.
수업은 어떻게 진행되나요?+
45분 실습 + 5분 코칭을 네 번 반복합니다. Claude App·Code, MCP, Skill, Plugin을 각각 설명한 뒤 하나의 업무 하네스로 연결하고, 각 기능은 설명으로 끝내지 않고 실제 업무 파일과 결과로 확인합니다. 기능 설명과 업무 결과의 비중은 대략 7:3입니다. 4~5인 소수정예라 설정과 연결에서 막히는 지점은 바로 옆에서 코칭해 드립니다. 이번 파일럿의 기록과 결과물에서는 개인정보를 다루지 않습니다.
일반 AI 강의와 뭐가 다른가요?+
대화창에서 한 번의 답을 얻는 연습이 아닙니다. 프로젝트 폴더에 업무 기준을 저장하고, MCP로 도구를 연결하고, 절차를 Skill로 만들고, Plugin으로 묶어 새 업무에서 다시 실행합니다.
무엇을 준비하나요?+
Windows/Mac 노트북 + 충전기, Claude 유료 계정이 필요합니다. 신청 확정 후 Desktop·VS Code·Claude Code CLI·실습용 읽기 Connector·Plugin 템플릿을 확인하는 사전 가이드를 보내드립니다.
Claude 이용료가 따로 드나요?+
네, 실습에 쓰는 Code 탭은 Claude 유료 플랜(Pro 이상, 월 $20 수준)이 필요합니다 — 무료 계정에는 열리지 않습니다. 이미 Pro를 쓰고 계시면 추가 비용이 없고, 처음이라면 사전 안내에서 가입 절차를 함께 도와드립니다. 세미나 후에도 계속 쓰실 도구라 이 비용은 수강료가 아니라 도구 구독료입니다.
지금 신청할 수 있나요?+
네. 정식 오픈 전 리허설 참가자 4~5명을 모집 중입니다. 신청 폼에서 8월 15일 이후 토요일 오후 1시~5시 중 가능한 일정을 복수 선택해 주세요. 4~5명이 가능한 날짜로 최종 확정해 1~2일 내 연락드립니다.
참가비는 어떻게 내나요?+
신청 폼 제출 후 확정 연락을 드릴 때 계좌 이체로 안내드립니다. 입금 확인 순으로 자리가 확정되며, 페이지에는 결제 정보를 두지 않습니다.
배운 걸 제 업무에 바로 쓸 수 있나요?+
4시간 만에 업무 전체를 자동화하지는 않습니다. 대신 업무 기준·MCP 연결 기록·Skill·Plugin 템플릿 한 세트를 가져가고, 마지막에 새 업무로 재실행해 어디까지 재사용되는지 확인합니다.
설치나 MCP 연결이 막히면요?+
사전에 무료로 점검합니다. 당일에도 해결이 길어지면 제공 원문·검증된 Skill·Plugin 템플릿으로 전환해 구조와 호출 실습을 계속합니다.
